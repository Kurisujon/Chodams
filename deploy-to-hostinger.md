# Deploy to Hostinger - Quick Guide

## Prerequisites
- Access to Hostinger File Manager or FTP/SFTP credentials
- Node.js installed locally to build assets

## Deployment Steps

### 1. Build Assets Locally
```bash
cd Chodams
npm run build
```

This creates optimized production files in `public/build/`

### 2. Files to Upload

#### **Always Upload (Required)**
- `public/build/` - **Entire folder** (delete old one first)
  - Contains compiled JavaScript and CSS
  - Generated by `npm run build`

#### **Optional (Source Files)**
- `resources/js/Pages/AdminDashboard.jsx`
- `resources/js/Services/PrintHandlerService.ts`
- `resources/js/Services/ChartRenderingCoordinator.js`
- `resources/js/Components/PrintButton.tsx`

### 3. Upload Methods

#### **Method A: Hostinger File Manager**
1. Login to Hostinger → File Manager
2. Navigate to your app directory (e.g., `public_html/chodams`)
3. **Delete** `public/build` folder on server
4. **Upload** new `public/build` folder from local
5. Clear browser cache (Ctrl+Shift+R)

#### **Method B: FTP/SFTP (FileZilla, WinSCP, etc.)**
1. Connect to your Hostinger server
2. Navigate to app directory
3. Delete remote `public/build` folder
4. Upload local `public/build` folder
5. Ensure file permissions are correct (755 for folders, 644 for files)

#### **Method C: SSH + Git (Advanced)**
```bash
# On your local machine
git add .
git commit -m "Your commit message"
git push origin main

# SSH into Hostinger
ssh username@your-server.com
cd /path/to/your/app
git pull origin main
npm install  # If package.json changed
npm run build
php artisan cache:clear
php artisan config:clear
php artisan view:clear
```

### 4. Post-Deployment Checklist

- [ ] Clear Laravel cache (if using SSH):
  ```bash
  php artisan cache:clear
  php artisan config:clear
  php artisan view:clear
  ```

- [ ] Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)

- [ ] Test the print functionality:
  - [ ] Click print button
  - [ ] Cancel print dialog
  - [ ] Verify charts remain intact
  - [ ] Check surveys per month chart is included in print

- [ ] Check browser console for errors (F12)

### 5. Troubleshooting

#### **Charts still broken after deployment**
- Clear browser cache completely
- Check if `public/build/manifest.json` was uploaded
- Verify file permissions on server (644 for files, 755 for folders)

#### **404 errors for assets**
- Ensure `public/build` folder structure is intact
- Check `.htaccess` file in `public/` directory
- Verify Laravel's `APP_URL` in `.env` matches your domain

#### **Changes not appearing**
- Hard refresh browser (Ctrl+Shift+R)
- Check if correct `public/build` folder was uploaded
- Verify `manifest.json` has new timestamps

### 6. Quick Commands Reference

```bash
# Build for production
npm run build

# Build and watch for changes (development)
npm run dev

# Clear all Laravel caches
php artisan optimize:clear

# Check Laravel logs
tail -f storage/logs/laravel.log
```

## Important Notes

1. **Always build before uploading** - Never upload source files without building
2. **Delete old build folder first** - Prevents file conflicts
3. **Clear caches** - Both server-side and browser-side
4. **Test thoroughly** - Especially print functionality
5. **Keep backups** - Download current `public/build` before replacing

## Hostinger-Specific Tips

- File Manager path is usually: `domains/yourdomain.com/public_html/`
- Use "Extract" feature if uploading as ZIP
- Check file permissions after upload
- Use Hostinger's built-in cache clearing tools
- Monitor error logs in Hostinger panel

## Support

If issues persist:
1. Check browser console (F12) for JavaScript errors
2. Check Laravel logs: `storage/logs/laravel.log`
3. Verify all files uploaded correctly
4. Test in incognito/private browsing mode
