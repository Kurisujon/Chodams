About

How to Use the System

  1. Log In: Use the admin username and password provided by the development team to log in.
  2. Navigation Tabs:
    • After logging in, the system displays four main tabs: Dashboard, Beneficiaries, Profile, and About.
  3. Dashboard Page:
    • The default page shows descriptive reports and data visualizations such as Pie Graphs and Bar Graphs.
    • At the top, four summary boxes are displayed:
      • Barangay: Clicking this box scrolls to the pie graph showing barangay-related data.
      • Classification of Informal Settlers: Clicking this box scrolls to the bar graph showing classifications.
      • Total Validated: Clicking this box redirects to the Beneficiaries tab, showing a table of validated beneficiaries where you can view details and search.
      • Total Approved: Clicking this box redirects to the Beneficiaries tab, showing a separate table for approved beneficiaries with similar functionalities.
  4. Beneficiaries Page:
    • This tab consists of two sections: Validated Beneficiaries and Approved Beneficiaries, each with separate tables.
    • Features include searching and viewing beneficiary details.
  5. Profile Page:
    • Manage validator applications: View, approve, or reject applications.
    • Approved validators are added to the Approved Validators List.
  6. About Tab:
    • Provides instructions on how to use the system and highlights key features for easy reference.

Key Features

  • Data Visualization: Create visual reports (graphs and tables) directly from the dashboard.
  • User-Friendly Interface: Simplified navigation for managing data efficiently.
  • Role-Based: Separated dashboard and user privileges.
  • Data Organization: dynamic listing and formatted sorting for quick viewing of data.
